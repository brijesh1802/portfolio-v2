# Brijesh Poojary — Portfolio

A minimalist, aesthetic personal portfolio built with **Vite + React + Tailwind CSS**.

## Features

- Clean dark theme with subtle gradients
- Fully responsive
- Smooth scroll navigation
- Sections: Hero, About, Experience, Projects, Skills, Education, Certifications, Contact
- Content sourced from professional resume

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Stack

- Vite 5
- React 18
- Tailwind CSS 3
- Inter + JetBrains Mono fonts

## Customization

Edit the data arrays inside each component under `src/components/` to update content.
